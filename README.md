# Déclic Emoji

Palette d’emoji gratuite pour Windows, avec 3 944 emoji et variantes répartis en neuf catégories. La recherche fonctionne hors ligne dans 14 langues, dont le français et l’anglais.

**[Télécharger DeclicEmoji.exe](https://github.com/loictinant/Declic-Emoji/releases/latest/download/DeclicEmoji.exe)** · [Notes de version](https://github.com/loictinant/Declic-Emoji/releases)

1. Lancez l’EXE sous Windows 10 version 2004 ou ultérieure, ou sous Windows 11.
2. Cliquez sur le smiley animé à côté de l’horloge ou appuyez sur **Ctrl + Maj + Espace**.
3. Un clic insère l’emoji au curseur ou le copie. Un clic droit ajoute un favori et un second le retire. Le bouton **Options** affiche les variantes et permet de copier l’emoji.

Le démarrage avec Windows est activé par défaut et se règle dans la palette. Le don PayPal est facultatif. Toutes les fonctionnalités sont gratuites.
